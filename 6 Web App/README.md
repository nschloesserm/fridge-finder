# The Fridge Finder (student concept)

A clickable demo of a recipe tool imagined for Graza, built for an MBA marketing plan.
**This is a class project. It is not made by, endorsed by, or affiliated with Graza.**

Enter what is in your fridge, get a recipe and the right bottle for the job, then "email" it to yourself.

- Recipes are scripted: 15 are built in, and the closest match to your ingredients is shown.
- No email is sent and nothing is stored. The sign-up step is a mock-up.
- It is a static site with no accounts, keys or tracking, and it works offline once loaded.

## Put it on GitHub Pages

1. On github.com, click **New repository**. Name it `fridge-finder`, set it to **Public**, and create it.
2. On the new repository's page, click **uploading an existing file**.
3. Drag in everything from this folder: `index.html`, `doodles.js`, `README.md`, `.nojekyll` and the `fonts` folder. Click **Commit changes**.
   (`.nojekyll` is a hidden file. On a Mac, press Cmd+Shift+. in Finder to see it. The site works without it.)
4. Go to **Settings → Pages**. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
5. After a minute or two the page shows your link: `https://YOUR-USERNAME.github.io/fridge-finder/`

## Presenting

- On a laptop it shows a phone frame with a short explainer beside it. On a phone it fills the screen.
- Add `?src=bottle` to the link (for example in a QR code) and the welcome screen says "Hello from the bottle".
- Tap the logo at the top of any screen to return to the start.
- To run it with no internet, open `index.html` directly from this folder.
